# Examples

`traces/` contains four small, synthetic converter fixtures generated by `build_examples.py`: a hot microwave trigger, two safe controls and terminal-state damage. `rules.json` contains a plain list of formulas; `report.json` is their saved offline evaluation.

`suite-report.json`, `suite-summary.csv` and `suite-report.html` are saved outputs from the 24-case seeded suite. Recreate its complete trace inputs with `python -m pipeline --output outputs/demo --seed 7 --variants 2`.

All examples are synthetic. They are separate from the team's actual simulator logs and the paper's benchmark results.
